# Contributing to FDM

Contributions are welcome! Please follow these guidelines:

1. **Fork & Branch**: Create a feature branch (`git checkout -b feature/my-feature`).
2. **Code Style**: Follow standard Kotlin & Jetpack Compose guidelines. Ensure builds pass (`./gradlew assembleDebug`).
3. **Pull Requests**: Open a pull request against `main` with a clear explanation of changes.
